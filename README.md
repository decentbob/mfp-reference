# mfp-reference

A TypeScript reference implementation of
[Money from First Principles](https://github.com/decentbob/money-from-first-principles):
one backing object `B = (K, P, R, E)`, claims held against it, wallets, and
the law.

Status: early. Transparent setting only. See `CLAUDE.md` for scope, the
invariants that bind the code, and how spec errors are handled.

## Running

```
npm install
npm test
```
